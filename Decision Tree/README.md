# Tugas Praktikum Decision Tree

## Tugas - Klasifikasi dengan Decision Tree

**Dataset:** https://www.kaggle.com/datasets/abbas829/bankruptcy

**File notebook:** `DT_NRP.ipynb`

Pada tugas ini kalian akan membangun model Decision Tree Classifier untuk menyelesaikan sebuah masalah klasifikasi. Fokus utama tugas ini adalah pemahaman cara kerja Decision Tree, khususnya:

- Perbandingan hasil antara kriteria split Gini Impurity dan Entropy
- Pengaruh regularisasi (max_depth) terhadap gejala overfitting

Pada tugas ini kalian akan membangun dan membandingkan:
- Decision Tree dengan kriteria Gini
- Decision Tree dengan kriteria Entropy
- Beberapa variasi max_depth untuk mengamati overfitting

Ikuti instruksi pada setiap cell notebook. Baca baik-baik keterangan pada setiap section sebelum menulis kode.
