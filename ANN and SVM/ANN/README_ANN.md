# Tugas Praktikum Artificial Neural Network (ANN)

## Tugas - Klasifikasi dengan ANN

**Dataset:** https://www.kaggle.com/datasets/blastchar/telco-customer-churn

**File notebook:** `ANN_NRP.ipynb`

Pada tugas ini kalian akan membangun model ANN (Multi-Layer Perceptron) Classifier untuk menyelesaikan sebuah masalah klasifikasi. Fokus utama tugas ini adalah pemahaman cara kerja ANN, khususnya:

- Perbandingan hasil antar fungsi aktivasi (ReLU, Tanh, Logistic/Sigmoid)
- Pengaruh ukuran arsitektur (`hidden_layer_sizes`) dan jumlah iterasi (`max_iter`) terhadap gejala overfitting

Pada tugas ini kalian akan membangun dan membandingkan:
- ANN dengan arsitektur dasar (satu hidden layer)
- ANN dengan variasi fungsi aktivasi
- Beberapa variasi ukuran arsitektur (jumlah neuron/hidden layer) untuk mengamati overfitting

Ikuti instruksi pada setiap cell notebook. Baca baik-baik keterangan pada setiap section sebelum menulis kode.
