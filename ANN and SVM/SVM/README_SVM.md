# Tugas Praktikum Support Vector Machine (SVM)

## Tugas - Klasifikasi dengan SVM

**Dataset:** https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data

**File notebook:** `SVM_NRP.ipynb`

Pada tugas ini kalian akan membangun model SVM Classifier untuk menyelesaikan sebuah masalah klasifikasi. Fokus utama tugas ini adalah pemahaman cara kerja SVM, khususnya:

- Perbandingan hasil antara kernel Linear dan kernel RBF
- Pengaruh parameter `C` dan `gamma` terhadap gejala overfitting/underfitting
- Pentingnya feature scaling untuk algoritma berbasis jarak seperti SVM

Pada tugas ini kalian akan membangun dan membandingkan:
- SVM dengan kernel Linear
- SVM dengan kernel RBF
- Beberapa variasi nilai `C` dan `gamma` untuk mengamati overfitting/underfitting

Ikuti instruksi pada setiap cell notebook. Baca baik-baik keterangan pada setiap section sebelum menulis kode.
