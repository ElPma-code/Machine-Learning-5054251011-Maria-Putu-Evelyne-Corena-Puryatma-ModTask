# Tugas Praktikum Regresi

Terdapat satu tugas pada modul ini. Tugas dikerjakan pada notebook yang disediakan.

## Tugas - Medical Cost Prediction

**Dataset:** Medical Cost Personal Dataset  
**Kaggle:** https://www.kaggle.com/mirichoi0218/insurance  
**File notebook:** `1_Regression_NRP.ipynb`

### Fitur

| Kolom | Tipe | Keterangan |
|---|---|---|
| `age` | Numerical | Usia penerima asuransi |
| `sex` | Categorical | Jenis kelamin |
| `bmi` | Numerical | Body Mass Index |
| `children` | Numerical | Jumlah tanggungan |
| `smoker` | Categorical | Status merokok |
| `region` | Categorical | Wilayah tempat tinggal |
| `charges` | Numerical | Biaya medis yang diprediksi |

Dataset tersedia dalam file `insurance.csv`

Pada tugas ini akan dibangun dan dibandingkan enam model regresi:
- Linear Regression
- Polynomial Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regressor
- Support Vector Regression

Tahapan pengerjaan:
1. Persiapan Dataset dan Eksplorasi Awal
2. Preprocessing
3. Eksperimen Model
4. Evaluasi
5. Analisis
6. Kesimpulan

## Ketentuan Pengerjaan

- Kerjakan secara mandiri.
- Isi bagian analisis dan kesimpulan berdasarkan hasil eksperimen sendiri.
- Ganti nama dan NRP pada tabel di bagian atas notebook.
- Gunakan preprocessing yang sesuai dengan karakteristik setiap model.
- Kumpulkan file notebook dengan format penamaan: `1_Regression_NRP.ipynb`.
